## List of Programs

### Program 1 - Employee Salary System
A company employs full-time employees, part-time employees, and interns. All employees share common information, but salary calculations vary by employment type.

### Program 2 - Payment Gateway
A payment gateway supports credit-card, UPI, net-banking, and wallet payments. All payment modes implement a common processing interface.

### Program 3 - Logistics Vehicle System
A logistics company manages trucks, delivery vans, and delivery bikes. All are vehicles with common identity and fuel attributes, while each has specialized properties.

### Program 4 - Bank Account System
Create a base `Account` class and derived classes `SavingsAccount`, `CurrentAccount`, and `FixedDepositAccount`. Include account number, holder name, balance, deposit, withdrawal, and interest-calculation features. Use virtual functions for account-specific behavior.

### Program 5 - Single Inheritance
To implement single inheritance using `Person` as a base class and `Student` as a derived class.

### Program 6 - Protected Member Access
To demonstrate how a derived class can access a protected base-class member.

### Program 7 - Public and Private Inheritance
To observe the effect of public and private inheritance on accessibility.

### Program 8 - Multilevel Inheritance
To implement multilevel inheritance using:  `Person → Employee → Manager`

### Program 9 - Hierarchical Inheritance
To implement hierarchical inheritance using `Vehicle` as a common base class.

### Program 10 - Multiple Inheritance
To demonstrate multiple inheritance using academic and sports records.

### Program 11 - Ambiguity in Multiple Inheritance
To resolve ambiguity when two base classes contain methods with the same name.

### Program 12 - Constructor and Destructor Order
To observe the construction and destruction order of a derived object.

### Program 13 - Parameterized Base Class Constructor
To initialize a parameterized base class from a derived-class constructor.

### Program 14 - Virtual Function Overriding
To override a virtual member function in a derived class.

### Program 15 - Abstract Base Class
To create an abstract base class using a pure virtual function.

### Program 16 - Diamond Inheritance
To solve duplicate-base ambiguity in diamond inheritance using a virtual base class.

### Program 17 - Friend Class
To demonstrate access to private data using a friend class.

### Program 18 - Nested Class
To create and use a nested class.

### Program 19 - Vehicle Rental Application
To build an inheritance-based vehicle rental application.

### Program 20 - Salary System
To develop a salary system using an abstract class and derived classes.
